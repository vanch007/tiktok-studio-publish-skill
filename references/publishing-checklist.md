# TikTok Studio 发布检查清单

## 会话确认

- 只使用用户刚确认的 Chrome/TikTok Studio 窗口；不要因为另一个窗口已登录就切换过去。
- 核对 URL、账号名称/头像、界面语言和当前作品/上传页。任一项不符就暂停。
- 记录批次的时区、文件顺序、说明模板、音乐池和音量目标。

## 单条流程

1. 选择一个 MP4，等待“已上传”与文件名出现。
2. 首条先做说明持久化探针：真实键盘输入、失焦、提交后回到“作品”页；作品行确认成功前不要批量继续。`set_value` 后的 AX 文本不算证据。
3. 写入说明和话题，触发输入事件后失焦；记录请求值、字段显示值和作品行显示值。声调被键盘通道剥离时，显式记录 `ascii_fallback`。
4. 添加音乐池中未连续使用的曲目；保留原声，设置平台音乐约 `-40 dB`。
5. 重新读取界面，确认曲名、音量数值、说明和封面未被重置。
6. 在点击预约前做标题终检；预约作品通常不能编辑，标题/说明未核对通过就不要提交。
7. 选择预约时间；TikTok Studio 通常要求至少提前 15 分钟。
8. 提交后等待处理，进入“作品”页核对作品行、时间、状态和链接/ID。预约后标题错误只能在用户确认后取消/删除并重传。

Computer Use 约束：每次点击、输入、滚动或快捷键后都调用 `get_app_state`；element index 只对最新状态有效。系统文件选择器中用 Go To Window 输入绝对路径，确认文件名后再点 Open。

## 停止条件

错窗口/错账号、文件顺序不明、说明回退为文件名、越南语乱码、音乐音量不是目标值、曲目连续重复、发布时间在过去、作品行未出现，均标为 `pending` 并停止，不要猜测或继续批量提交。
